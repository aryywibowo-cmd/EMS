# EMS - Aplikasi HP (Android & iPhone)

Pembungkus PWA untuk web app Google Apps Script "Employee Monitoring System - Plaza Toyota Tendean".
Halaman ini memuat web app di dalam layar penuh, dengan ikon, nama "EMS", dan layar pembuka sendiri.

- Ubah alamat web app: `index.html`, variabel `APP_URL`.
- Bila mengubah file, naikkan versi `CACHE` di `sw.js` (mis. `ems-shell-v2`).
